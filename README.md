**🔥 Featured: PinePoint**

PinePoint sends 10 simulated users through a pull request's Vercel preview, each on its own Pine Computer with a real browser. It posts what breaks as a review on the PR, with steps to reproduce each bug and a link to the live browser. I built it with one teammate at the Pine Computer Hackathon, where it won.

[Live demo](https://pinepoint-rho.vercel.app) · [Source](https://github.com/vihuynh72/pinepoint)

**💡 Why I build**

Projects matter when someone uses them on a bad day. Most CS students want to build something that matters, so here is the loop I use:

1. Start with a problem you have hit yourself.
2. Build the small version this week.
3. Put it in front of one real person and watch where they get stuck.
4. Fix that, then do it again.
